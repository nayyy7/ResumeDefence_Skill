## 项目经历

### CampusRAG：面向高校课程资料的智能问答系统

**时间：** 2024 年 3 月 — 2024 年 11 月

**项目背景：**
高校课程资料（课件、教材、习题、答疑记录）分散在多个平台，学生在复习和做作业时经常找不到答案或需要反复翻阅。现有方案要么依赖通用搜索引擎，要么只支持关键词检索，无法理解复杂的学习问题。

**项目目标：**
构建一个基于 RAG 的智能问答系统，整合多门课程资料，帮助学生用自然语言提问并获取准确回答。

**技术方案：**
- 使用 LangChain 构建 RAG pipeline
- Embedding 模型使用 text-embedding-ada-002
- 向量数据库使用 Chroma
- LLM 使用 GPT-3.5-turbo 进行答案生成
- 设计了多路召回策略（向量检索 + 关键词检索）
- 使用 Prompt Engineering 控制回答风格和引用来源

**我的职责：**
- 负责核心 RAG 模块的设计和实现
- 参与系统整体架构设计
- 负责部分数据预处理工作

**项目成果：**
- 回答准确率提升 30%
- 用户满意度显著提高
- 减少了 LLM 幻觉问题
- 系统已在校内小范围试用

**技能标签：** LLM, RAG, LangChain, Embedding, 向量数据库, Prompt Engineering
